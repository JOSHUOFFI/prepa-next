The duplicate `legacy_english_*` copy set and one extra generated row were archived. The final 200 contain 100 uncited legacy records and 100 `prepa_authored` records. The old 8 keyword-generated topics are inactive. Difficulty is 108 easy, 67 medium and 25 hard. All 200 questions are assigned, have four distinct options and exactly one correct answer. Correct positions are A/B/C/D = 50 each.
- **Mathematics:** Source is `data/legacy-question-bank.ts` (`Mathematics`, 150 non-null M1–M150 records; two null array entries). The 51 archived source items cover logarithms, advanced algebra/inequalities, abstract operations, matrices, calculus, complex numbers and one ambiguous trigonometric equation. One malformed two-option admin question was also archived. The final 200 contain 99 uncited legacy records and 101 `prepa_authored` records. The hierarchy reuses the verified JSS1–3 NERDC topic extraction (36 pages) and adds 10 clearly `review_required` implementation topics. There are 200 assigned questions, all with four distinct options and exactly one correct answer. Difficulty is 86 easy, 99 medium and 15 hard; correct positions are A/B/C/D = 50 each. One superseded implementation topic remains inactive for auditability.
- Both subjects retain global `class_id` and `term_id` question scope so the existing exam loader continues to retrieve them. The JSS curriculum tree itself carries the source class scope.
- The catalogue rows still store `mapped_no_questions`; no readiness status was changed. Existing exam selector logic sees 200 active global questions for each and reports Available.

## Scope and Risks

Only English Studies and Mathematics were populated in this pass. Business Studies and CRS meet the numerical selector threshold but are not content-ready until their correct-answer and duplicate defects are remediated. Several other target subjects have no canonical production mapping; they remain unavailable rather than receiving speculative subject identities. The Nigerian-language and foreign-language banks need verified language review before authoring. The production exam API remains global-pool based, so class-specific CBT selection is not established by these topic assignments.
